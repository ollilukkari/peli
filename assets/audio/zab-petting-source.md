# Zab petting sound

The game uses an excerpt of the reference video supplied for this feature.
The video itself and its embedded metadata are not included in the game.

- Excerpt: 0.19–9.75 seconds; the silent video ending is excluded.
- Encoding: mono MP3, 44.1 kHz, 96 kbit/s; short edge fades avoid clicks.
- Playback: a decoded Web Audio loop on the sound-effects channel, stopping immediately when the final Zab petting stroke finishes. The upward boost uses a separate synthesized sound effect.

The project owner confirmed permission to use and distribute this excerpt in the
public game and its GitHub repository on 2026-09-19. This note records that
confirmation; it does not grant a separate license for other uses of the recording.
