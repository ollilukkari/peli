# Ulkoasuluonnosten generointiohjeet

Tuotettu sisäänrakennetulla imagegen-työkalulla. Kuvat ovat suunnitteluluonnoksia; ajonaikainen peligrafiikka tehdään canvas-koodilla. Alla ovat käytetyt generointiohjeet. Viitekuvien konekohtaisia polkuja ei tallenneta.

Viite: käyttäjän antama pieni kuva valkoisesta pikselipupusta niityllä.

Keep same effective pixel grid and crisp integer-sized square pixel edges across all variants, NOT smooth vector, no gradients on rabbits, no painterly detail, no outfits/bows/accessories.
