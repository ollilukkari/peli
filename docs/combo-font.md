# Combo typography

The canvas combo number and the HUD combo badge use **Caprasimo Regular**.
The Latin WOFF2 is bundled with the game, preloaded from the same origin,
and included in the complete offline release. Starting a round waits for
the font to load, including starts through the touch playfield. No locally
installed font or external font service is needed at runtime.

The start-menu and installation-page title remains the existing fixed
Cooper Black SVG artwork; see [title artwork](title-artwork.md).

Caprasimo is distributed under the SIL Open Font License 1.1. The copyright
notice and complete license are in `assets/fonts/OFL.txt`, published and
cached alongside the font. The font file is an unmodified Google Fonts
Latin webfont; the original font name is retained.
